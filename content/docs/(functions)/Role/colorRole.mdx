---
title: "$colorRole"
---

Changes the color of given role ID

## Usage
```cc
$colorRole[Role ID;Primary Color (i.e hex or int);Second Color (optional);Third Color (optional)]
```

### Example (Primary Color)
```cc
$colorRole[Role name;green]
```

### Example (Gradient)
```cc
$colorRole[Role name;green;red]
```

---
title: "$memberJoinedDate"
---

Retrieves the date and time a member joined the server. You can specify a user ID or use it without any arguments to get the join date of the command executor.

## Usage
```cc
$memberJoinedDate[userID;format(optional)] or $memberJoinedDate
``` 

- `userID`: (Optional) The ID of the member you want to retrieve the join date for. If omitted, it will use the command executor's join date.
- `format`: (Optional) Specifies what to return. Can be either `date`, `time`, or `ms`. If omitted, it will return `date`

**Examples:**

<DiscordMessages>
    <DiscordMessageUser>
        !!exec $memberJoinedDate[725721249652670555;date]
    </DiscordMessageUser>
    <DiscordMessageBot>
        Tue Oct 28 2025 10:53:08 GMT+0000 (Coordinated Universal Time)
    </DiscordMessageBot>
</DiscordMessages>

<DiscordMessages>
    <DiscordMessageUser>
        !!exec $memberJoinedDate[725721249652670555;time]
    </DiscordMessageUser>
    <DiscordMessageBot>
        10 months 3 weeks 6 days 4 hours 17 minutes and 14 seconds
    </DiscordMessageBot>
</DiscordMessages>

<DiscordMessages>
    <DiscordMessageUser>
        !!exec $memberJoinedDate[725721249652670555;ms]
    </DiscordMessageUser>
    <DiscordMessageBot>
        1761648788208
    </DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"Timezone Information"}>

Date functions default to UTC timezone. You can customize the timezone by following the instructions [here](/Date/timezone).

</Callout>

---
title: "$hour"
---

This command returns the current hour (in 24-hour format).

#### Usage
```cc
$hour
```

**Example:**

This example shows how to use the `$hour` command in a custom command.

<br/>

<DiscordMessages>
<DiscordMessageUser>
!!exec $hour
</DiscordMessageUser>
<DiscordMessageBot>
19
</DiscordMessageBot>
</DiscordMessages>

---
title: "$hour"
---

This command returns the current hour (in 24-hour format).

## Usage

```cc
$hour
```

**Example:**

This example shows how to use the `$hour` command in a custom command.

<Discord>
    <Message>!!exec $hour</Message>
    <Message bot>19</Message>
</Discord>

<Callout type="info" title={"Timezone Considerations"}>

Date functions use the UTC timezone by default. You can change the timezone for your bot. [Learn More](/Date/timezone)

---
title: "$day"
---

Returns the current date. Optionally, you can also retrieve the day of the week.

#### Usage
```cc
$day[yes/no (optional)]
```

*   **`$day`**: Returns the current date (day of the month).
*   **`$day[yes]`**: Returns the current date (day of the month) followed by the day of the week.

**Example:**

<br/>

<DiscordMessages>
<DiscordMessageUser>
!!exec $day $day[yes]
</DiscordMessageUser>
<DiscordMessageBot>
25 Saturday
</DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"Timezone Information"}>

Date functions default to the UTC timezone. You can customize the timezone used by your bot. [Learn More](/Date/timezone)

</Callout>

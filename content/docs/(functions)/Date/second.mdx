---
title: "$second"
---

Returns the current second (0-59).

## Usage
```cc
$second
```

This function is simple! It just retrieves the current second of the minute.

**Example:**

<br/>

<DiscordMessages>
<DiscordMessageUser>
!!exec $second
</DiscordMessageUser>
<DiscordMessageBot>
56
</DiscordMessageBot>
</DiscordMessages>

<Badge type="danger" text="Premium ONLY!" vertical="middle" />

Sends the output of the code to the message author's DMs or to the DMs of a specified user.

## Usage

```cc
$sendDM[userID;message;return message id or undefined, if message could not be send (yes/no, default is no)]
```

- `userID`: (Optional) The ID of the user to send the DM to. If omitted, the DM will be sent to the message author.
- `message`: The message to send in the DM.
- `return message ID`: (Optional) Determines whether to return the ID of the sent DM. If the DM failed to send, then the return value would be `undefined`. Defaults to `no` if not provided.

**Example 1: Sending a DM to the message author multiple times.**

<Discord>
    <Message>
        !!exec $sendDM[$authorID;I can add this multiple times in my code! This
        is time 1] $sendDM[$authorID;I can add this multiple times in my code!
        This is time 2]
    </Message>
</Discord>

<Discord>

    <Message bot>
        I can add this multiple times in my code! This is time 2
    </Message>
</Discord>

<Callout type="info" title={"Note"}>

You can send embeds using the [Message Curl Format](/Other/curl). This allows you to create richly formatted messages within the DM.

</Callout>

<Callout type="info" title={"Related Functions"}>

- `$sendMessage`: Sends a message to the channel where the command was used.

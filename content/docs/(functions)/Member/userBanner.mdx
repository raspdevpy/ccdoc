---
title: "$userBanner"
---

Returns the banner URL of a user.

## Usage

```bash
$userBanner[userID]
```
1. **userID** - (Optional) default value: `$authorID`. The ID of a user you want to return banner URL from. If no banner is found, returns `undefined`.

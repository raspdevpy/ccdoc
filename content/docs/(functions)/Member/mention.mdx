---
title: "$mention"
---

Returns a mention of a user.

## Usage

```cc
$mention[userID]
```

1. **userID** - (Optional) default value: `$authorID`. The ID of user to get mentioned.

## Example

#### Using $mention

How to use $mention for author or other user

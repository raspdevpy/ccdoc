title: "$globalName"
---

Returns the global name of the user

## Usage

```cc
$globalName[userID]
```
1. **userID** - (Optional) default value: `$authorID`. The user ID of the user you want to return global name from.

## Example

#### Using $globalName

How to return the global name from author

<Discord>
<Message>

</Message>

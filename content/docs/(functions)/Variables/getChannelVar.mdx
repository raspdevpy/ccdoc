title: "$getChannelVar"

Gets a channel variable value

## Usage

```cc
$getChannelVar[variable;channelID(optional)]
```

<Discord>
    <Message>!!exec $getChannelVar[Creator]</Message>
    <Message bot>Mido</Message>
</Discord>

**Note:** The return value will be `undefined` if the variable was not defined for that channel.

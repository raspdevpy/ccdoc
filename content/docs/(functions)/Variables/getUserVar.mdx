---
title: "$getUserVar"
---

Gets a user variable value

#### Usage
```cc
$getUserVar[variable;User ID (Optional)]
```

#### Example
<DiscordMessages>
<DiscordMessageUser>
!!exec Your warnings: $getUserVar[warns]
</DiscordMessageUser>
<DiscordMessageBot>
Your warnings: 4
</DiscordMessageBot>
<DiscordMessageUser>
!!exec Other user's warnings: $getUserVar[warns;12346786512312]
</DiscordMessageUser>
<DiscordMessageBot>
Other user's warnings: 1
</DiscordMessageBot>
</DiscordMessages>

**Note:** The return value will be `undefined` if the variable was not defined for that user.

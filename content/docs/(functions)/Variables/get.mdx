---
title: "$get"
---

retrieve variable defined by `$let`

## Usage
```cc
$get[varname;value if not exists] or $varname
```

### Example 1:
<DiscordMessages>
<DiscordMessageUser>
!!exec $let[orange;10] <br/> $get[orange] or $orange
</DiscordMessageUser>
<DiscordMessageBot>
10 or 10
</DiscordMessageBot>
</DiscordMessages>

### Example 2 (Use default value if not exists):
<DiscordMessages>
<DiscordMessageUser>
!!exec Your name is $get[name;Mido]
</DiscordMessageUser>
<DiscordMessageBot>
Your name is Mido
</DiscordMessageBot>
</DiscordMessages>

---
title: "$get"
---

retrieve variable defined by `$let`

## Usage

```cc
$get[varname;value if not exists] or $varname
```

### Example 1:

<Discord>
    <Message>!!exec $let[orange;10] $get[orange] or $orange</Message>
    <Message bot>10 or 10</Message>
</Discord>

### Example 2 (Use default value if not exists):

<Discord>
    <Message>!!exec Your name is $get[name;Mido]</Message>
    <Message bot>Your name is Mido</Message>
</Discord>

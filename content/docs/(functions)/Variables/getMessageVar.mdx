---
title: "$getMessageVar"
---

Gets a message variable value

## Usage

```cc
$getMessageVar[variable;messageID(optional)]
```

<Discord>
    <Message>!!exec $getMessageVar[data]</Message>
    <Message bot>Mido</Message>
</Discord>

**Note:** The return value will be `undefined` if the variable was not defined for that message.

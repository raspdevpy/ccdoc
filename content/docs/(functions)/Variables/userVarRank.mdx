---
title: "$userVarRank"
---

Return user var rank returned by $userleaderboard for a single user

## Usage

```cc
$uservarRank[Variable name;Order Type (optional) (asc/desc, default is desc);User ID (optional)]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec Your rank is $userVarRank[xp]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
Your rank is 3
</DiscordMessageBot>
</DiscordMessages>

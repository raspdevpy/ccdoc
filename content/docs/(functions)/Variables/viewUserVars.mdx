---
title: "$viewUserVars"
---

View a list of all the variables that are defined for a specific user

## Usage

```cc
$viewUserVars[User ID;Separator]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $viewUsersVars[$authorID]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
xp, money, bonus
</DiscordMessageBot>
</DiscordMessages>

---
title: "$randomMention"
---

Returns a random mention from the current server. This function is useful for things like raffles, giveaways, or randomly selecting a user.

## Usage:

```cc
$randomMention
```

**Example:**

This example shows how to use `$randomMention` to mention a random user in a command.

<Discord>
    <Message>!!exec $randomMention</Message>
    <Message bot>@Lisa</Message>
</Discord>

<Callout type="error" title={"Warning"}>

The mentions returned by this function are pulled from the server's cached member list. This means that if all members haven't been cached yet (common in larger servers, especially those below "Tier 5" boosting), it may not include _every_ member in the server. For best results, ensure your bot has access to all members.

</Callout>

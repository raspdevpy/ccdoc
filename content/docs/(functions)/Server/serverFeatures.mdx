---
title: "serverFeatures"
---

Returns the server features. This function returns a comma-separated list of features enabled on the server.

## Usage

```cc
$serverFeatures
```

<Discord>
    <Message>!!exec $serverFeatures</Message>
    <Message bot>
        Preview Enabled, Threads Enabled, Member Verification Gate Enabled, New
        Thread Permissions, News, Community, Welcome Screen Enabled
    </Message>
</Discord>

---
title: "$getServerInvite"
---

Creates an invite link to the current server.

## Usage

```cc
$getServerInvite
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec My server invite is: $getServerInvite<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
My server invite is: https://discord.gg/midoworkshopsv
</DiscordMessageBot>
</DiscordMessages>

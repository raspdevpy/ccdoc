---
title: "$membersCount"
---

Returns the amount of users in your server/guild!

## Usage
```cc
$membersCount
```

```cc
!!exec There are `$membersCount` members in the server!
```

**Example:**

<Discord>
<Message>
!!exec There are `$membersCount` members in the server!
</Message>
<Message bot>
There are `599` members in the server
</Message>
</Discord>

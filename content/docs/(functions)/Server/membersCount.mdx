---
title: "$membersCount"
---

Returns the amount of users in your server/guild!

## Usage
```cc
$membersCount
```

```cc
!!exec There are `$membersCount` members in the server!
```

**Example:**

<DiscordMessages>
<DiscordMessageUser>
!!exec There are `$membersCount` members in the server!
</DiscordMessageUser>
<DiscordMessageBot>
There are `599` members in the server
</DiscordMessageBot>
</DiscordMessages>

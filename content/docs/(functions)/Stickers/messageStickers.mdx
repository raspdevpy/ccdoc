---
title: "$messageStickers"
---

To return the user message stickers (id)\
**Index**: starts with 1, leaving it empty return all stickers ids separated by `, `

## Usage

```cc
$messageStickers[Index]
```

### Example:

<Discord>
    <Message>
        !!exec $messageStickers[1]
    </Message>
    <Message bot>992970796031017080</Message>
</Discord>

**Related Functions:** `$sticker`

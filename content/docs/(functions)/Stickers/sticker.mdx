---
title: "$sticker"
---

To return an information about a sticker using ID\
**Info** can be: name, desc, url, tags, time

## Usage

```cc
$sticker[Sticker ID;name;Info]
```

### Example:

<Discord>
    <Message>
        !!exec $sticker[992974663099629588;name]
    </Message>
    <Message bot>Smiley</Message>
</Discord>

**Related Functions:** `$messageStickers`

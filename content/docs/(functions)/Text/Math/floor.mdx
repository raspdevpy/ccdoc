---
title: "$floor"
---

return the largest integer less than or equal to a given number

## Usage

```cc
$floor[Number]
```

### Example:

<Discord>
    <Message>!!exec $floor[2.4]</Message>
    <Message bot>2</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $floor[2.9]</Message>
    <Message bot>2</Message>
</Discord>

---
title: "$ceil"
---

rounds a number up to the next largest integer

## Usage

```cc
$ceil[Number]
```

### Example:

<Discord>
    <Message>!!exec $ceil[1.3]</Message>
    <Message bot>2</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $ceil[3.5]</Message>
    <Message bot>4</Message>
</Discord>

---
title: "$mathMin"
---

Return the smallest number from a list of numbers

## Usage

```cc
$mathMin[Number 1;Number 2;Number 3;...]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $mathMin[100;50;150]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
50
</DiscordMessageBot>
</DiscordMessages>

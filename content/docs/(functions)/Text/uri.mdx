---
title: "$uri"
---

Decodes or Encodes a url Example when you encode a url 'hello world' = 'hello%20world'

## Usage

```cc
$uri[decode/encode;text]
```

### Example (Encoding):

<Discord>
    <Message>!!exec $uri[encode;Hello World]</Message>
    <Message bot>Hello%20World</Message>
</Discord>

### Example (Decoding):

<Discord>
    <Message>!!exec $uri[decode;Hello%20World]</Message>
    <Message bot>Hello World</Message>
</Discord>

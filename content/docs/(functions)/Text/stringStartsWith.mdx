---
title: "$stringStartsWith"
---

Determines whether given message starts by another message or not

## Usage

```cc
$stringStartsWith[message;text]
```

### Example:

<Discord>
    <Message>!!exec $stringStartsWith[Hello World;Hello]</Message>
    <Message bot>true</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $stringStartsWith[Hello World;Hate]</Message>
    <Message bot>false</Message>
</Discord>

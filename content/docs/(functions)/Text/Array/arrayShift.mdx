---
title: "$arrayShift"
---

Removes and returns the first element in an array.

## Usage

```cc
$arrayShift[array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Mido/Rake/Azz;/]
        first one is $arrayShift
        after it is $arrayShift
        after it is $arrayShift
    </Message>
    <Message bot>
        first one is Mido
        after it is Rake
        after it is Azz
    </Message>
</Discord>

---
title: "$arraySort"
---

Sorts an array, created with `$textSplit`.
Can be sorted numerically or alphabetically, or depending on occurrences.

## Usage

```cc
$arraySort[Ascending (yes/no, default is no);Sort Type;array name (optional)]
```

### Sort Types:

`num`: Sort Numerically\
`alpha`: Sort Alphabetically\
`frequent`: Sort By how many element got repeated

### Example (Sort Occurrences):

<Discord>
    <Message>
        !!exec $textSplit[3.Mido 1.Azz 2.Rake 2.Rake 3.Mido 3.Mido 4.Finkz; ]
        $arraySort[no;frequent]
    </Message>
    <Message bot>The sorted list is 3.Mido 2.Rake 4.Finkz 1.Azz</Message>
</Discord>

### Example (Sort Numerically):

<Discord>
    <Message>
        !!exec $textSplit[1. Azz 3.Mido 2.Rake 4.Finkz; ] $arraySort[yes;num]
        The sorted list is $arrayJoin[ ]
    </Message>

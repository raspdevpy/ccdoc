---
title: "$arrayClear"
---

Deletes an array.

## Usage

```cc
$arrayClear[array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Hello World; ]
        Before=$arrayJoin[, ]
        $arrayClear
        After=$arrayJoin[, ]
    </Message>
    <Message bot>
        Before=Hello, World
        After=
    </Message>
</Discord>

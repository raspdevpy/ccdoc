---
title: "$arrayInclude"
---

To check if a value exists in the array. Returns `true` if the value exists, otherwise returns `false`.

## Usage

```cc
$arrayInclude[Value;array name (optional)]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $textSplit[Mido/Rake/Azz;/]<br />$arrayInclude[Rake]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

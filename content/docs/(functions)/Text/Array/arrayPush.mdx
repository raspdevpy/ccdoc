---
title: "$arrayPush"
---

Adds an element to the end of an array.

## Usage

```cc
$arrayPush[Value;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $arrayPush[Mido]
        $arrayPush[Rake]
        $arrayPush[Azz]
        $arrayJoin[/]
    </Message>
    <Message bot>Mido/Rake/Azz</Message>
</Discord>

---
title: "$arrayUnshift"
---

Adds an element to the start of the array.

## Usage

```cc
$arrayUnshift[value;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $arrayUnshift[Mido] $arrayUnshift[Rake] $arrayUnshift[Azz]
        $arrayJoin[/]
    </Message>
    <Message bot>Azz/Rake/Mido</Message>
</Discord>

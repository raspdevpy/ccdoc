---
title: "$arrayJoin"
---

Joins an array created using `$textSplit` with a specific separator.

## Usage

```cc
$arrayJoin[Separator (optional);array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Rake/Mido/Azz;/]
        $arrayJoin[, ]
    </Message>
    <Message bot>Rake, Mido, Azz</Message>
</Discord>

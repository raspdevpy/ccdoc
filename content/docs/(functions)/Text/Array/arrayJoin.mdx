---
title: "$arrayJoin"
---

Joins an array created using `$textSplit` with a specific separator.

## Usage

```cc
$arrayJoin[Separator (optional);array name (optional)]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $textSplit[Rake/Mido/Azz;/]<br />$arrayJoin[, ]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
Rake, Mido, Azz
</DiscordMessageBot>
</DiscordMessages>

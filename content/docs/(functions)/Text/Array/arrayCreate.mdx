---
title: "$arrayCreate"
---

Creates an array from a list.

## Usage

```cc
$arrayCreate[List;separator;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $arrayCreate[Mido/Rake/Azz;/]
        1 is $arrayGet[1]
        2 is $arrayGet[2]
        3 is $arrayGet[3]
    </Message>
    <Message bot>
        1 is Mido
        2 is Rake
        3 is Azz
    </Message>
</Discord>

### Note on Separator:

You can use regex as separator i.e `/separator/`

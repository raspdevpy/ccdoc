---
title: "$arrayPop"
---

Removes, and returns the last element in an array.

## Usage

```cc
$arrayPop[array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Mido/Rake/Azz;/]
        last one is $arrayPop
        before it is $arrayPop
        before it is $arrayPop
    </Message>
    <Message bot>
        last one is Azz
        before it is Rake
        before it is Mido
    </Message>
</Discord>

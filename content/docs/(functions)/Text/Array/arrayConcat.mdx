---
title: "$arrayConcat"
---

Merge new array with the current array

## Usage

```cc
$arrayConcat[List;separator;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $arrayCreate[Mido/Rake;/]
        $arrayConcat[Azz/Finkz;/]
        $arrayJoin[, ]
    </Message>
    <Message bot>
        Mido, Rake, Azz, Finkz
    </Message>
</Discord>

### Note on Separator:

You can use regex as separator i.e `/separator/`

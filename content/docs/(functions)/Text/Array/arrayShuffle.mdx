---
title: "$arrayShuffle"
---

To shuffle an existing array.

## Usage

```cc
$arrayShuffle[array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Rake/Azz/Mido;/]
        $arrayShuffle
        $arrayJoin[/]
    </Message>
    <Message bot>Azz/Mido/Rake</Message>
</Discord>

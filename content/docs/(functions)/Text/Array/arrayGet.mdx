---
title: "$arrayGet"
---

Returns the value of an element at the specified index in an array.

## Usage

```cc
$arrayGet[index;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Mido/Rake/Azz;/]
        First is $arrayGet[1]
        Second is $arrayGet[2]
        Third is $arrayGet[3]
    </Message>
    <Message bot>
        First is Mido
        Second is Rake
        Third is Azz
    </Message>
</Discord>

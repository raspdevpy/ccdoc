---
title: "$arraySet"
---

Sets the value of an index in an array.

## Usage

```cc
$arraySet[index;value;array name (optional)]
```

### Example:

<Discord>
    <Message>
        !!exec $textSplit[Mido/Rake/Azz;/]
        Before: $arrayGet[3]
        $arraySet[3;Finkz]
        After: $arrayGet[3]
    </Message>
    <Message bot>
        Before: Azz
        After: Finkz
    </Message>
</Discord>

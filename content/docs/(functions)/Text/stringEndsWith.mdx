---
title: "$stringEndsWith"
---

Checks if given message ends with given text

## Usage

```cc
$stringEndsWith[message;text]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $stringEndsWith[Hello World;World]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $stringEndsWith[Hello World;Discord]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false
</DiscordMessageBot>
</DiscordMessages>

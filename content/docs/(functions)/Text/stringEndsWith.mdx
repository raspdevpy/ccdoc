---
title: "$stringEndsWith"
---

Checks if given message ends with given text

## Usage

```cc
$stringEndsWith[message;text]
```

### Example:

<Discord>
    <Message>!!exec $stringEndsWith[Hello World;World]</Message>
    <Message bot>true</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $stringEndsWith[Hello World;Discord]</Message>
    <Message bot>false</Message>
</Discord>

---
title: "$isUserMention"
---

To check if text provided satisfy discord user mention format or not

## Usage

```cc
$isUserMention[Text]
```

### Example:

<Discord>
    <Message>!!exec $isUserMention[abc]</Message>
    <Message bot>false</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $isUserMention[&#60;@!1234567890&#62;]</Message>
    <Message bot>true</Message>
</Discord>

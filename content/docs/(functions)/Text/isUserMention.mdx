---
title: "$isUserMention"
---

To check if text provided satisfy discord user mention format or not

## Usage

```cc
$isUserMention[Text]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $isUserMention[abc]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $isUserMention[&#60;@!1234567890&#62;]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

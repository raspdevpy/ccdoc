---
title: "$textLength"
---

Counts character of a text, or the user's message.

## Usage

```cc
$textLength or $textLength[text]
```

### Example:

<Discord>
    <Message>!!exec $textLength[Mido]</Message>
    <Message bot>4</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $textLength[Hello]</Message>
    <Message bot>6</Message>
</Discord>

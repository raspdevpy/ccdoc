---
title: "$regexCheck"
---

To check if a text matches a regex or not, returns true or false

## Usage

```cc
$regexCheck[Text;Regex;Flags]
```

### Example (Check If Text is letters):
<DiscordMessages>
<DiscordMessageUser>
!!exec $regexCheck[ABC;^[a-zA-Z]+$]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $regexCheck[A2B;^[a-zA-Z]+$]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false
</DiscordMessageBot>
</DiscordMessages>

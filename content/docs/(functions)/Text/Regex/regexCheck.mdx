---
title: "$regexCheck"
---

To check if a text matches a regex or not, returns true or false

## Usage

```cc
$regexCheck[Text;Regex;Flags]
```

### Example (Check If Text is letters):

<Discord>
    <Message>!!exec $regexCheck[ABC;^[a-zA-Z]+$]</Message>
    <Message bot>true</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $regexCheck[A2B;^[a-zA-Z]+$]</Message>
    <Message bot>false</Message>
</Discord>

---
title: "$mentioned"
---

Returns the ID of the mentioned user

## Usage

```cc
$mentioned[mention number or all;return author ID (yes/no)(optional)]
```

### Example:

<Discord>
    <Message>
        !!exec First mention is $mentioned[1] All mentions are: $mentioned[all]
    </Message>
    <Message bot>
        First mention is 788361834360864808 All mentions are:
        788361834360864808, 840526017260945468
    </Message>
</Discord>

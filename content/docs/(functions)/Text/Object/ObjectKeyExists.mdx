---
title: "$ObjectKeyExists"
---

Checks if given key is present in the object. Returns `true` or `false`.

## Usage

```php
$ObjectKeyExists[Key;...]
```
1. **Key(s)** - Key to check it's existence. You can put as many nested keys as needed.

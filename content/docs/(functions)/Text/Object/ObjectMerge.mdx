---
title: "$ObjectMerge"
---

Merge the current object with another object, it overwrites the conflicted keys

## Usage

```bash
$ObjectMerge[object]
```

### Example:
<DiscordMessages>
<DiscordMessage roleColor="#ffcc9a" author="Member">
!!exec $objectSet[name;Mido]<br />$objectMerge[\{"country":"EG"}]<br />$objectGet<br /><br />

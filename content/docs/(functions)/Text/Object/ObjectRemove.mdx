---
title: "$ObjectRemove"
---

To remove a key from the object

## Usage

```cc
$ObjectRemove[Key;Key...(Optional)]
```

### Example:
<DiscordMessages>
<DiscordMessage roleColor="#ffcc9a" author="Member">
!!exec $objectSet[Name;Mido]<br />
$objectSet[Country;EG]<br />
Before: $getObject<br />
$objectRemove[Name]<br />
After: $getObject
</DiscordMessage>

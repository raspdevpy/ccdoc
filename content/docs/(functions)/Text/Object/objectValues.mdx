---
title: "$objectValues"
---

Return the Object values with seperator between each value

## Usage

```cc
$objectValues[Seperator (optional, default:, );Nested Propery 1;Nested Property 2]
```

### Example (Get values of nested property):

<Discord>
    <Message>
        !!exec $objectSet[name;Mido] $objectSet[age;300] $objectValues
    </Message>
    <Message bot>Mido, 300</Message>
</Discord>

### Example:

<Discord>
    <Message>
        !!exec $objectSet[user;name;Mido] $objectSet[user;id;1234]
        $objectSet[user;weapon;Sword] $objectValues[/;user]
    </Message>
    <Message bot>Mido/1234/Sword</Message>
</Discord>

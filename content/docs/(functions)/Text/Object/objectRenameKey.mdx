---
title: "$objectRenameKey"
---

allows you to rename a key in your object

## Usage

```cc
$objectRenameKey[old key;new key name]
```

### Example:

<Discord>
<Message>
!!exec $objectSet[name;Mido]
Before: $objectGet
$objectRenameKey[name;nick]
After: $objectGet
</Message>
<Message bot>
Before: \{"name":"Mido"}
After: \{"nick":"Mido"}
</Message>
</Discord>

### Example (Nested Key):

<Discord>
<Message>
!!exec $objectSet[user;name;Mido]
Before: $objectGet
$objectRenameKey[user;name;nick]
After: $objectGet
</Message>
<Message bot>
Before: \{"user":\{"name":"Mido"}}
After: \{"user":\{"nick":"Mido"}}
</Message>
</Discord>

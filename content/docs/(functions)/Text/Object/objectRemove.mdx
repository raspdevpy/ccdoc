---
title: "$objectRemove"
---

To remove a key from the object

## Usage

```cc
$objectRemove[Key;Key...(Optional)]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $objectSet[Name;Mido]<br />
$objectSet[Country;EG]<br />
Before: $getObject<br />
$objectRemove[Name]<br />
After: $getObject
</DiscordMessageUser>
<DiscordMessageBot>
Before: \{"Name":"Mido","Country":"EG"}
<br />
After: \{"Country":"EG"}
</DiscordMessageBot>
</DiscordMessages>

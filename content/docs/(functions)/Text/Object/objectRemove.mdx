---
title: "$objectRemove"
---

To remove a key from the object

## Usage

```cc
$objectRemove[Key;Key...(Optional)]
```

### Example:

<Discord>
<Message>
!!exec $objectSet[Name;Mido]
$objectSet[Country;EG]
Before: $getObject
$objectRemove[Name]
After: $getObject
</Message>
<Message bot>
Before: \{"Name":"Mido","Country":"EG"}
After: \{"Country":"EG"}
</Message>
</Discord>

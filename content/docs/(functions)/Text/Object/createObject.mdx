---
title: "$createObject"
---

Creates an object that can be used later.

## Usage

```cc
$createObject[object string]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $createObject[\{"name":"Mido","age":110}]<br />Your name is $objectGet[name]<br />Your age is $objectGet[age]<br /><br />
</DiscordMessageUser>

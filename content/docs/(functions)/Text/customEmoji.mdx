---
title: "$customEmoji"
---

Returns a custom emoji

## Usage

```cc
$customEmoji[name or id]
```

### Example (Using Custom Emoji Name):

<Discord>
    <Message>!!exec $customEmoji[yes]</Message>
    <Message bot>
        <Embed
            image="https://i.imgur.com/E174Ey0.png"
        ></Embed>
    </Message>
</Discord>

### Example (Using Custom Emoji ID):

<Discord>
    <Message>
        !!exec $customEmoji[833252579873259521]
    </Message>
    <Message bot>
        <Embed
            image="https://i.imgur.com/7t3gZNn.png"
        ></Embed>
    </Message>
</Discord>

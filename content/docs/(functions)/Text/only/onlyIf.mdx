---
title: "$onlyIf"
---

Continue the execution only if certain [expression](/Other/expression) is satisfied, otherwise stop the execution and send the error message.
In theory $onlyif can replace all other $onlyFor with the proper [expression](/Other/expression)
#### Usage: `$onlyif[Expression;error message]`

#### Example: `$onlyIf[$username==Mido;You are not mido]`

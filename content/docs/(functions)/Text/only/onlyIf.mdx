---
title: "$onlyIf"
---

Continue the execution only if certain [expression](/CodeReferences/ref.expression) is satisfied, otherwise stop the execution and send the error message.
In theory $onlyif can replace all other $onlyFor with the proper [expression](/CodeReferences/ref.expression)
## Usage
```cc
$onlyif[Expression;error message]
```

#### Example: `$onlyIf[$username==Mido;You are not mido]`

</Callout>

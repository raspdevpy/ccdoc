---
title: "$onlyIfMessageContains"
---

Continues the execution only if 'text' contains all provided words, returns the `error message` parameter if it does not.

## Usage

```cc
$onlyIfMessageContains[text;word1;word2;...;error message]
```

## Example

<Discord>
    <Message>
        !!exec $onlyIfMessageContains[$username[$authorID];mem;My username
        doesn't contain `mem`] My username contains `mem`!
    </Message>
    <Message bot>My username contains `mem`</Message>
</Discord>

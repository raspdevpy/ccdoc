---
title: "$isTicket"
---

checks if a channel is a ticket or not created with $newTicket function,returns true or false

#### Usage
```cc
$isTicket
``` or `$isTicket[channelid]`
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isTicket | $isTicket[891210194925809695]
</DiscordMessageUser>
<DiscordMessageBot>
false | true
</DiscordMessageBot>
</DiscordMessages>

---
title: "$isValidHex"
---

checks if the given int or hex code or [color name](/CodeReferences/ref.embed.colors) is valid  ,returns true,false

## Usage
```cc
$isValidHex[int or hexcode or color name]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isValidHex[#ffffff] , $isValidHex[test], $isValidHex[Red]
</DiscordMessageUser>
<DiscordMessageBot>
true , false, true
</DiscordMessageBot>
</DiscordMessages>

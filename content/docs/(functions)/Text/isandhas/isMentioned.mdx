---
title: "$isMentioned"
---

Checks if the given id of userID/roleID/channelID/everyone is Mentioned ,returns true or false

## Usage

```cc
$isMentioned[userID/roleID/channelID/everyone]
```

Example:

<Discord>
    <Message>!!exec $mention $isMentioned[$authorID]</Message>
    <Message bot>true</Message>
</Discord>

**Function difficulty:** <Badge type="tip" text="Easy" vertical="middle" />

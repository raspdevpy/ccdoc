---
title: "$isEmoji"
---

Checks if the given Emoji is a default emoji ,returns true or false

## Usage

```cc
$isEmoji[emoji]
```

Example:

<Discord>
    <Message>!!exec $isEmoji[:smile:]</Message>
    <Message bot>true</Message>
</Discord>

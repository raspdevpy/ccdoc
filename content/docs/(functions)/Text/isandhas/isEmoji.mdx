---
title: "$isEmoji"
---

Checks if the given Emoji is a default emoji ,returns true or false 

#### Usage: `$isEmoji[emoji]`
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isEmoji[:smile:]
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

---
title: "$isEmoji"
---

Checks if the given Emoji is a default emoji ,returns true or false 

#### Usage
```cc
$isEmoji[emoji]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isEmoji[:smile:]
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

**Function difficulty:** <Badge type="tip" text="Easy" vertical="middle" />

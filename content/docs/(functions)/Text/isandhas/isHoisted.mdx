---
title: "$isHoisted"
---

Checks if the given id of role is hoisted above all the other roles ,returns true or false 

#### Usage
```cc
$isHoisted[roleid]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isHoisted[$roleID[test]]
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

---
title: "$isHoisted"
---

Checks if the given id of role is hoisted above all the other roles ,returns true or false

## Usage

```cc
$isHoisted[roleid]
```

Example:

<Discord>
    <Message>!!exec $isHoisted[$roleID[test]]</Message>
    <Message bot>true</Message>
</Discord>

---
title: "$isValidLink"
---

checks if the given Link / url is valid ,returns true,false

#### Usage
```cc
$isValidLink[Link]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isValidLink[https://example.com] 
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

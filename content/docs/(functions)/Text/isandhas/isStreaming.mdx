---
title: "$isStreaming"
---

To check whether user is streaming in a voice channel or not (only cached users)

## Usage

```cc
$isStreaming[User ID]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec Is $username Streaming?: $isStreaming<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
Is Mido Streaming?: false
</DiscordMessageBot>
</DiscordMessages>

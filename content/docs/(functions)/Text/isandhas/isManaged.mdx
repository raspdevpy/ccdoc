---
title: "$isManaged"
---

Checks if the given id of role is Managed ,returns true or false 

#### Usage
```cc
$isManaged[roleid]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isManaged[$roleID[Custom Command]]
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

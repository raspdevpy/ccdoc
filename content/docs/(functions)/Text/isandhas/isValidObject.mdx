---
title: "$isValidObject"
---

checks if the given Object is valid ,returns true,false

#### Usage
```cc
$isValidObject[Object]
```
Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $isValidObject[\{"key":"value"}]
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>

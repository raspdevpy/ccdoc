---
title: "$checkContains"
---

checks if given message contains any of the texts

## Usage

```cc
$checkContains[message;text1;text2;...]
```

### Example 1:
<DiscordMessages>
<DiscordMessageUser>
!!exec $checkContains[Mido is good;good]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example 2:
<DiscordMessages>
<DiscordMessageUser>
!!exec $checkContains[Mido is good;bad]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false
</DiscordMessageBot>
</DiscordMessages>

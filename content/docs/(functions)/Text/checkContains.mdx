---
title: "$checkContains"
---

checks if given message contains any of the texts

## Usage

```cc
$checkContains[message;text1;text2;...]
```

### Example 1:

<Discord>
    <Message>!!exec $checkContains[Mido is good;good]</Message>
    <Message bot>true</Message>
</Discord>

### Example 2:

<Discord>
    <Message>!!exec $checkContains[Mido is good;bad]</Message>
    <Message bot>false</Message>
</Discord>

---
title: "$thumbnail"
---

Adds a thumbnail to a message embed.

## Usage

```cc
$thumbnail[YOUR URL HERE]
```

<Discord>
    <Message>
        !!exec $title[Title]
        $description[Description]
        $thumbnail[$userAvatar]
    </Message>
    <Message bot>
        <Embed
            title="Title"
            thumbnail="member"
        >
            Description
        </Embed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{thumbnail: Your link here}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

Link escapes are needed, use `\` to escape characters. Read [me](/Guide/syntax) to see more

</Callout>

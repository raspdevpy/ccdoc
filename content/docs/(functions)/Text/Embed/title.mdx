---
title: "$title"
---

Adds a title to a message embed.

#### Usage: `$title[YOUR TITLE TEXT HERE;url(optional)]`
<br/>
<DiscordMessages>
<DiscordMessage roleColor="#ffcc9a" author="Member">
!!exec $title[This is a title]
</DiscordMessage>
<DiscordMessage bot roleColor="#0099ff" author="Custom Command" avatar="https://media.discordapp.net/avatars/725721249652670555/781224f90c3b841ba5b40678e032f74a.webp">
<DiscordEmbed slot="embeds" embedTitle="This is a title">
</DiscordEmbed>
</DiscordMessage>
</DiscordMessages>

Or with url

<DiscordMessages>
<DiscordMessage roleColor="#ffcc9a" author="Member">
!!exec $title[This is a title;https://discord.com]
</DiscordMessage>
<DiscordMessage bot roleColor="#0099ff" author="Custom Command" avatar="https://media.discordapp.net/avatars/725721249652670555/781224f90c3b841ba5b40678e032f74a.webp">
<DiscordEmbed slot="embeds" embedTitle="This is a title" url="https://discord.com">
</DiscordEmbed>
</DiscordMessage>
</DiscordMessages>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>


Use: `{title: Your title here}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Other/syntax)

</Callout>

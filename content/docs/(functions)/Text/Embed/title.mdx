---
title: "$title"
---

Adds a title to a message embed.

## Usage

```cc
$title[YOUR TITLE TEXT HERE;url(optional)]
```

<Discord>
    <Message>!!exec $title[This is a title]</Message>
    <Message bot>
        <DiscordEmbed slot="embeds" embedTitle="This is a title"></DiscordEmbed>
    </Message>
</Discord>

Or with url

<Discord>
    <Message>!!exec $title[This is a title;https://discord.com]</Message>
    <Message bot>
        <DiscordEmbed
            slot="embeds"
            embedTitle="This is a title"
            url="https://discord.com"
        ></DiscordEmbed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{title: Your title here}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

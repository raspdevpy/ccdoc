---
title: "$title"
---

Adds a title to a message embed.

## Usage

```cc
$title[YOUR TITLE TEXT HERE;url(optional)]
```

<Discord>
    <Message>
        !!exec $title[This is title]
    </Message>
    <Message bot>
        <Embed title="This is title"></Embed>
    </Message>
</Discord>

Or with url

<Discord>
    <Message>
        !!exec $title[This is a title;https://ccommandbot.com]
    </Message>
    <Message bot>
        <Embed
            title="This is a title"
            url="https://discord.com"
        ></Embed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{title: Your title here}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

---
title: "$addTimestamp"
---

Adds a timestamp to a message embed.

## Usage

```cc
$addTimestamp
```

or `$addTimestamp[ms]`

<Discord>
    <Message>
        !!exec $title[Title]
        $addTimestamp
    </Message>
    <Message bot>
        <Embed title="Title" footer="Today at 12:00"></Embed>
    </Message>
</Discord>

or with specified Time

<Discord>
    <Message>
        !!exec $title[Title]
        $addTimestamp[$dateToTime[09/13/2021]]
    </Message>
    <Message bot>
        <Embed title="Title" footer="9/13/21, 00:00"></Embed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{timestamp:ms}`

</Callout>

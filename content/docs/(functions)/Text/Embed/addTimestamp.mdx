---
title: "$addTimestamp"
---

Adds a timestamp to a message embed.

## Usage

```cc
$addTimestamp
```

or `$addTimestamp[ms]`

<Discord>
    <Message>!!exec $addTimestamp</Message>
    <Message bot>
        <DiscordEmbed slot="embeds" timestamp="09/12/2021"></DiscordEmbed>
    </Message>
</Discord>

or with specified Time

<Discord>
    <Message>!!exec $addTimestamp[$parseTime[13/09/2021]]</Message>
    <Message bot>
        <DiscordEmbed slot="embeds" timestamp="09/13/2021"></DiscordEmbed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{timestamp:ms}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>
````

---
title: "$description"
---

Adds a description to a message embed.

## Usage
```cc
$description[your text]
```
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $description[This is a description]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds">
This is a description
</DiscordEmbed>
</DiscordMessageBot>
</DiscordMessages>

Description with hyperlinks:
Usage:  `\[link\](https://ccommandbot.com "tooltip(optional)")`
<DiscordMessages>
<DiscordMessageUser>
!!exec $description[This is a description with \[link\](https://ccommandbot.com "tooltip")]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds">
This is a description <a href="https://ccommandbot.com" target="_blank" title="tooltip">hello</a>
</DiscordEmbed>
</DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>


Use: `{description:your text}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

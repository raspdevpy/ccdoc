---
title: "$description"
---

Adds a description to a message embed.

## Usage

```cc
$description[your text]
```

<Discord>
    <Message>!!exec $description[This is description]</Message>
    <Message bot>
        <Embed>This is description</Embed>
    </Message>
</Discord>

Description with hyperlinks:
Usage: `\[link\](https://ccommandbot.com "tooltip(optional)")`

<Discord>
    <Message>
        !!exec $description[This is description with \[link\](https://ccommandbot.com)]
    </Message>
    <Message bot>
        <Embed>
            This is description with [link](https://ccommandbot.com)
        </Embed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{description:your text}`

</Callout>

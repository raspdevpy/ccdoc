---
title: "$footer"
---

Adds a footer to a message embed with an optional icon url

## Usage

```cc
$footer[text;icon url(optional)]
```

<Discord>
    <Message>!!exec $footer[This is a fantastic embed footer]</Message>
    <Message bot>
        <DiscordEmbed slot="embeds">
            <span slot="footer">This is a fantastic embed footer</span>
        </DiscordEmbed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{footer: Your text here:icon url(optional)}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

Link escapes are needed, use `\` to escape characters. Read [me](/Guide/syntax) to see more

</Callout>

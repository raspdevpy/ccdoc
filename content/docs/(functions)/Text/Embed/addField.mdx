---
title: "$addField"
---

Adds fields to a message embed.

## Usage

```cc
$addField[title;value;inline(yes/no default=yes)(optional)]
```

<Discord>
    <Message>
        !!exec $addField[title;value1]
        $addField[title2;value2]
        $addField[title3;value3]
        $addField[title4;value4]
    </Message>
    <Message bot>
        <Embed>
            <Fields>
                <Field title="title">
                    value1
                </Field>
                <Field title="title2">
                    value2
                </Field>
                <Field title="title3">
                    value3
                </Field>
                <Field title="title4">
                    value4
                </Field>
            </Fields>
        </Embed>
    </Message>
</Discord>

$addField with hyperlinks:
Usage: `\[link\](https://ccommandbot.com "tooltip(optional)")`

<Discord>
    <Message>
        !!exec $addField[Title;This is a field with a \[link\](https://ccommandbot.com)]
    </Message>
    <Message bot>
        <Embed>
            <Fields>
              <Field title="Title">
                    This is a field with a [link](https://ccommandbot.com)
                </Field>
            </Fields>
        </Embed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{field:name:value:inline(yes/no default=yes)(optional)}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

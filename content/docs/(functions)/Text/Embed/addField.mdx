---
title: "$addField"
---

Adds fields to a message embed.

## Usage

```cc
$addField[title;value;inline(yes/no default=yes)(optional)]
```

<Discord>
    <Message>
        !!exec $addField[title;value;no] $addField[title2;value2]
        $addField[title3;value3] $addField[title4;value4]
    </Message>
    <Message bot>
        <DiscordEmbed slot="embeds">
            <DiscordEmbedFields slot="fields">
                <DiscordEmbedField fieldTitle="title">value</DiscordEmbedField>
                <DiscordEmbedField inline fieldTitle="title2">
                    value2
                </DiscordEmbedField>
                <DiscordEmbedField inline fieldTitle="title3">
                    value3
                </DiscordEmbedField>
                <DiscordEmbedField inline fieldTitle="title4">
                    value4
                </DiscordEmbedField>
            </DiscordEmbedFields>
        </DiscordEmbed>
    </Message>
</Discord>

$addField with hyperlinks:
Usage: `\[link\](https://ccommandbot.com "tooltip(optional)")`

<Discord>
    <Message>
        !!exec $addField[title;This is a field with
        \[link\](https://ccommandbot.com "tooltip")]
    </Message>
    <Message bot>
        <DiscordEmbed slot="embeds">
            <DiscordEmbedFields slot="fields">
                <DiscordEmbedField fieldTitle="title">
                    This is a description{" "}
                    <a
                        href="https://ccommandbot.com"
                        target="_blank"
                        title="tooltip"
                    >
                        hello
                    </a>
                </DiscordEmbedField>
            </DiscordEmbedFields>
        </DiscordEmbed>
    </Message>
</Discord>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>

Use: `{field:name:value:inline(yes/no default=yes)(optional)}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

---
title: "$author"
---

Adds an author to a message embed, with an optional icon url and/or hyperlink.

## Usage
```cc
$author[text;icon url(optional);hyperlink(optional)]
```
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $author[text]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds" authorName="text">
</DiscordEmbed>
</DiscordMessageBot>
<DiscordMessageUser>
!!exec $author[text;$authorAvatar]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds" authorName="text" authorIcon="https://cdn.discordapp.com/attachments/654503812593090602/665721745466195978/blue.png">
</DiscordEmbed>
</DiscordMessageBot>
<DiscordMessageUser>
!!exec $author[text;$authorAvatar;https://ccommandbot.com]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds" authorName="text" authorIcon="https://cdn.discordapp.com/attachments/654503812593090602/665721745466195978/blue.png" authorUrl="https://ccommandbot.com">
</DiscordEmbed>
</DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"Do you want to add an embed inside a Function as paramter like $sendmessage[text]"}>


Use: `{author:text:icon url(optional):hyper link(optional)}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Other/syntax)

</Callout>

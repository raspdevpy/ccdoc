---
title: "$color"
---

sets the color of the embed

## Usage
```cc
$color[Hex or Color Name]
```
## Accepted Color Names
Check this [page](/CodeReferences/ref.embed.colors)

## Example 1: Using it in function format
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $color[#0099ff]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds" color="#0099ff">
</DiscordEmbed>
</DiscordMessageBot>
</DiscordMessages>

## Example 2: Using In Curl Format
<br/>
<DiscordMessages>
<DiscordMessageUser>
!!exec $sendMessage[<br />\{desc:You are awesome}<br />\{color:#0099ff}<br />]
</DiscordMessageUser>
<DiscordMessageBot>
<DiscordEmbed slot="embeds" color="#0099ff" description="">
You are awesome
</DiscordEmbed>
</DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"To color an embed inside a function like $sendmessage[text]"}>


Use: `{color:hex or colorname or RANDOM or TRANSPARENT}`
Example: `{color:#0099ff}`

</Callout>

<Callout type="error" title={"Please be aware!!"}>

If you add any `:` in this function it will error! Check out [this](/Guide/syntax)

</Callout>

---
title: "$isChannelMention"
---

To check if text provided satisfy discord channel mention format or not

## Usage

```cc
$isChannelMention[Text]
```

### Example:

<Discord>
    <Message>!!exec $isChannelMention[abc]</Message>
    <Message bot>false</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $isChannelMention[&#60;#1234567890&#62;]</Message>
    <Message bot>true</Message>
</Discord>

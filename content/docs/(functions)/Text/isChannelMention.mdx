---
title: "$isChannelMention"
---

To check if text provided satisfy discord channel mention format or not

## Usage

```cc
$isChannelMention[Text]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $isChannelMention[abc]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $isChannelMention[&#60;#1234567890&#62;]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true
</DiscordMessageBot>
</DiscordMessages>

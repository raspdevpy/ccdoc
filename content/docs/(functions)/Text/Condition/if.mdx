---
title: "$if"
---

Checks An expression and executes code Only if that expression is true

## Shortest Syntax

```cc
$if[EXPRESSION]
	CODE
$endIf
```

## What is expression?

Read about it [here](/Other/expression)

##### Example 1 only with $if

Since the username of the executor is Tom it executed the if block

<Discord>
    <Message>!!exec $if[$username==Tom] Oh, you are Tom! $endIf</Message>
    <Message bot>Oh, you are Tom!</Message>
</Discord>

##### Example 2 only with $if and $else

Since the username is not Tom it executes the else block

<Discord>
    <Message>
        !!exec $if[$username==Tom] Oh, you are Tom! $else You are not Tom!
        $endIf
    </Message>
    <Message bot>You are not Tom!</Message>
</Discord>

##### Example 3 $if , $else and $elseif

Since the username is not Tom .It goes to the next if statement ,which is $elseif[$username==Lisa] and it will execute it

<Discord>
    <Message>
        !!exec $if[$username==Tom] Oh, you are Tom! $elseif[$username==Lisa] You
        are Lisa! $endelseIf $else I don't know you :C $endIf
    </Message>
    <Message bot>You are Lisa!</Message>
</Discord>

##### Example 4 $if , $else and $elseif

Since the username is not Tom .It goes to the next if statement ,which is $elseif[$username==Lisa] and it will execute it

Info: The second else if will get never executed ,because it will exit the statement after the first true expression

<Discord>
    <Message>
        !!exec $if[$username==Tom] Oh, you are Tom! $elseif[$username==Lisa]
        1.You are Lisa! $endelseIf $elseif[$username==Lisa] 2.You are Lisa!
        $endelseIf $else I don't know you :C $endIf
    </Message>
    <Message bot>1.You are Lisa!</Message>
</Discord>

##### Example 5 multiplie condtions in if with && or ||

Expression can accept multiple conditions, use `||` or `&&` as separators

`||` is for OR  
`&&` is for AND

Example:

```cc
$username==Mido&&$country==Egypt
```

Condition 1: `$username==Mido`
Condition 2: `$country==Egypt`
But this expression will only be true only if both condition 1 **AND** (because of &&) condition 2 is `true`

The Example below will execute since $username==Tom is false but the second expression is true .It wouldn't work with &&

<Discord>
    <Message>
        !!exec $if[$username==Tom||$username=Lisa] You are Tom or Lisa $endIf
    </Message>
    <Message bot>You are Tom or Lisa</Message>
</Discord>

The Example will only execute if the username is Lisa and their tag is 9999

<Discord>
    <Message>
        !!exec $if[$username==Lisa&&$discriminator=9999] You are Lisa with tag
        9999 $endIf
    </Message>
    <Message bot>You are Lisa with tag 9999</Message>
</Discord>

---
title: "$conditional"
---

return A if condition is true, B if condition is false

## Usage

```cc
$conditional[condition;A;B]
```

### Example:

<Discord>
    <Message>
        !!exec $conditional[$username==Mido;You are Mido;You are Rake]
    </Message>
    <Message bot>You are Mido</Message>
</Discord>

### Output (if Rake run the command):

You are Rake

---
title: "$conditional"
---

return A if condition is true, B if condition is false

## Usage

```cc
$conditional[condition;A;B]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $conditional[$username==Mido;You are Mido;You are Rake]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
You are Mido<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Output (if Rake run the command):
You are Rake

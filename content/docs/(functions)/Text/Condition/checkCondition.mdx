---
title: "$checkCondition"
---

Checks if given expression is true or false.

## Usage

```cc
$checkCondition[Expression]
```

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $checkCondition[$username==Mido]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
true<br /><br />
</DiscordMessageBot>
</DiscordMessages>

### Example:
<DiscordMessages>
<DiscordMessageUser>
!!exec $checkCondition[10&#60;5]<br /><br />
</DiscordMessageUser>
<DiscordMessageBot>
false
</DiscordMessageBot>
</DiscordMessages>

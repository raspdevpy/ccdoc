---
title: "$checkCondition"
---

Checks if given expression is true or false.

## Usage

```cc
$checkCondition[Expression]
```

### Example:

<Discord>
    <Message>!!exec $checkCondition[$username==Mido]</Message>
    <Message bot>true</Message>
</Discord>

### Example:

<Discord>
    <Message>!!exec $checkCondition[10&#60;5]</Message>
    <Message bot>false</Message>
</Discord>

---
title: "$mentionedRoles"
---

Returns the ID of one of the roles that was mentioned by the user

## Usage

```cc
$mentionedRoles[number]
```

<Discord>
    <Message>
        !!exec $mentionedRoles[1]{" "}
        <mention type="role" color="#70f0b4">
            Support
        </mention>
    </Message>
    <Message bot>869243918787686432</Message>
</Discord>

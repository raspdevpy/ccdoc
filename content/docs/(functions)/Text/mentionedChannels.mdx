title: "$mentionedChannels"

Returns the ID of one of the channels that was mentioned by the user

#### Usage: `$mentionedChannels[number]`
<br/>

<DiscordMessageUser>
!!exec $mentionedChannels[1] <mention type="channel">user-support</mention>
</DiscordMessageUser>

</DiscordMessageBot>

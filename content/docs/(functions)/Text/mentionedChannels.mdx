---
title: "$mentionedChannels"
---

Returns the ID of one of the channels that was mentioned by the user

## Usage

```cc
$mentionedChannels[number]
```

<Discord>
    <Message>
        !!exec $mentionedChannels[1]{" "}
        <mention type="channel">user-support</mention>
    </Message>
    <Message bot>869243919697846379</Message>

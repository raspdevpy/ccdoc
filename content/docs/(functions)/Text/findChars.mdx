---
title: "$findChars"
---

Takes all the letters from given string and returns them alone.

## Usage

```cc
$findChars[string]
```

## Example

<Discord>
<Message>
!!exec $findChars[$username]
</Message>
<Message bot>
Member
</Message>
</Discord>

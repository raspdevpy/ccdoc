title: "$thread"
---

Gets info trom a thread.

## Usage:

```cc
$thread[Thread ID;Type]
```

Example:

<Discord>
    <Message>!!exec &lt;@!$thread[owner]&gt;</Message>
    <Message bot mention>
        <Mention />
    </Message>
</Discord>

<Accordions>
<Accordion title={"Valid objects for \"Type\""}>

- `archivedat`
- `duration`
- `id`
- `members`
- `memberscount`
- `messagescount`
- `name`
- `owner`
- `locked`
- `parent`

</Accordion>
</Accordions>

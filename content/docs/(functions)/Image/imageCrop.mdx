---
title: "$imageCrop"
---

Crop a defined image from image builder

## Usage

```cc
$imageCrop[image name;x;y;width;height]
```

### Example:

<Discord>
    <Message>
        !!exec $imageCreate[300;300] // Create Image Frame
        $imageLoadFromURL[avatar;$replaceText[$authorAvatar;webp;png]]
        $imageCrop[avatar;0;0;100;100] // crop the image from position (0, 0)
        with size 100 $imageDraw[avatar] $image[$imageOutput]
    </Message>
    <Message bot>[image]</Message>
</Discord>

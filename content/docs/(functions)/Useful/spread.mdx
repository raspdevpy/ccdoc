---
title: "$spread"
---

spreads text as arguments inside functions

## Usage

```cc
$spread[separator (optional, default: ,);data to spread]
```

#### Example:

<Discord>
    <Message>
        !!exec Your color is $randomtext[$spread[,;Blue,Yellow,Green]]
    </Message>
    <Message bot>Your color is Yellow</Message>
</Discord>

---
title: "$redirectErrors"
---

To redirect any kind of errors to a specific channel, by default errors will appear in the execution channel

## Usage:

`$redirectErrors[Channel ID]`

#### Example:

<Discord>
    <Message>
        !!exec $modifyChannelPerms[$authorID;-sendmessages;$channelID]
        $redirectErrors[Channel ID]
    </Message>
</Discord>

<Discord>
    <Message bot>
        ❌ Invalid channel ID in
        $modifyChannelPerms[787695068306866198;-sendmessages;879380104768278608]
    </Message>
</Discord>

<Callout type="error">

The way `$modifyChannelPerms` shown here is **NOT** correct!

Check the `$modifyChannelPerms` for the correct usage

</Callout>

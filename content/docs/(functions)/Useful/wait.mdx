---
title: "$wait"
---

Will wait an X time, before executing the code below it.

## Usage:

`$wait[time]`

#### Example:

<Discord>
    <Message>
        !!exec $sendMessage[This part gets executed before the 10s] $wait[10s]
        $sendMessage[This part after the 10s]
    </Message>
    <Message bot>This part gets executed before the 10s</Message>
    <Message bot>This part after the 10s</Message>
</Discord>

<Callout type="info">

If you want to wait more then 1m, we suggest you use `$setTimeout`

</Callout>

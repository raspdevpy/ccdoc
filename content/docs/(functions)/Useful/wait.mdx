---
title: "$wait"
---

Will wait an X time, before executing the code below it.

#### Usage: 
`$wait[time]`

#### Example:
<br/>
<DiscordMessages>
<DiscordMessage roleColor="#ffcc9a" author="Member">
<DiscordMarkdown>
!!exec $sendMessage[This part gets executed before the 10s]
<br />
$wait[10s]
<br />
$sendMessage[This part after the 10s]
</DiscordMarkdown>
</DiscordMessage>

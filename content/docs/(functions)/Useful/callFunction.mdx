---
title: "$callFunction"
---

To call a user-defined function created with `$function`


#### Usage: 
`$callFunction[Function Name;Argument 1 (optional);Argument 2....(optional)]`

#### Example:
```cc
$callFunction[printHello;Mika]
``` 

Call the function, using `$callFunction`

---
title: "$suppressErrors"
---

Suppress all the errors and sends a custom one. \{error} will contain the error that was thrown.

## Usage: 
`$suppressErrors[message]`

#### Example:
<br/>
<DiscordMessages>
<DiscordMessageUser>
<DiscordMarkdown>
!!exec $suppressErrors[Wrong usage of $modifyChannelPerms]
$modifyChannelPerms[$authorID;-sendmessages;$channelID]
</DiscordMarkdown>
</DiscordMessageUser>
<DiscordMessageBot>
Wrong usage of $modifyChannelPerms
</DiscordMessageBot>
</DiscordMessages>

<Callout type="info" title={"Note"}>

You can send embed using [Message Curl Format](/CodeReferences/ref.message_curl_format)

</Callout>

<Callout type="error">

The way `$modifyChannelPerms` shown here is **NOT** correct! 

Check the `$modifyChannelPerms` for the correct usage

</Callout>

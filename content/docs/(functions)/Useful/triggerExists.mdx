---
title: "$triggerExists"
---

Check if a trigger with the specified token exists

## Usage

```cc
$triggerExists[Token]
```

### Example (An existing trigger):
<Discord>
<Message>
!!exec $triggerExists[fx1d53]
</Message>
<Message bot>
true
</Message>
</Discord>

### Example (not available trigger):
<Discord>
<Message>
!!exec $triggerExists[abcdef]
</Message>
<Message bot>
false
</Message>
</Discord>

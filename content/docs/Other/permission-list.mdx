Several bot functions, such as `$modifyChannelPerms` and `$modifyRolePerms`, require you to specify permission names.

## Available Permissions

Here are all permissions and their descriptions that the bot currently supports.

| Permission                | Description                         |
| :------------------------ | :---------------------------------- |
| `admin`                   | Administrator access                |
| `manageserver`            | Manage server settings              |
| `kick`                    | Kick members                        |
| `ban`                     | Ban members                         |
| `manageroles`             | Manage roles                        |
| `managechannels`          | Manage channels                     |
| `managewebhooks`          | Manage webhooks                     |
| `managemessages`          | Manage messages                     |
| `viewauditlog`            | View audit logs                     |
| `managenicknames`         | Manage nicknames                    |
| `sendmessages`            | Send text messages                  |
| `readmessages`            | View message history                |
| `movemembers`             | Move members between voice channels |
| `viewguildinsights`       | Access server analytics             |
| `mentioneveryone`         | Mention @everyone and @here         |
| `embedlinks`              | Post links with previews            |
| `viewchannel`             | View channels                       |
| `createinvite`            | Generate invite links               |
| `mutemembers`             | Mute members                        |
| `speak`                   | Speak in voice channels             |
| `deafenmembers`           | Deafen members                      |
| `attachfiles`             | Upload files                        |
| `connect`                 | Join voice channels                 |
| `addreactions`            | Add reactions                       |
| `speakpriority`           | Speak uninterrupted                 |
| `ttsmessage`              | Send TTS messages                   |
| `externalemoji`           | Use emojis from other servers       |
| `vad`                     | Use voice activity detection        |
| `changenickname`          | Change own nickname                 |
| `slashcommand`            | Use slash commands                  |
| `speakrequest`            | Request to speak in stage channels  |
| `managethreads`           | Manage threads                      |
| `publicthreads`           | Create public threads               |
| `privatethreads`          | Create private threads              |
| `externalstickers`        | Use stickers from other servers     |
| `canstream`               | Stream video in voice channels      |
| `manageevents`            | Manage scheduled events             |
| `createpublicthreads`     | Create public/announcement threads  |
| `createprivatethreads`    | Create private threads              |
| `sendmessagesinthreads`   | Send messages in threads            |
| `embeddedactivities`      | Use Discord Activities              |
| `moderatemembers`         | Timeout members                     |
| `sendvc`                  | Send voice messages                 |
| `usesoundboard`           | Use soundboard                      |
| `useexternalsounds`       | Use sounds from other servers       |
| `viewcreatormonetization` | View monetization analytics         |
| `createexpression`        | Create emojis, stickers, sounds     |

| `sendpolls`               | Send polls                          |

| `pinmessages`             | Pin/unpin messages                  |
| `bypassslowmode`          | Bypass slowmode                     |
| `setvcstatus`             | Set voice channel status            |
| `manageexpression`        | Manage emojis, stickers, sounds     |

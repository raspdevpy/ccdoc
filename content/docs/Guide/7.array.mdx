Array is a list of items that you can loop through, or join with a specific separator.  
Once you create an array, you can use functions to modify it or retrieve information from it.

## Indexes

Each element in an array has a unique index number that identifies its position. Our array starts from index 1.

## Example

```cc
$arrayCreate[Apple Banana Kiwi; ] // List split by space

// Retrieve items
First item: $arrayGet[1]
Last item: $arrayGet[$arrayLength]
All items: $arrayJoin[/]
```
